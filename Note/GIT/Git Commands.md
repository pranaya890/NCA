
- to get git version
	```
	git --version
	```
- to get git help
```
git --help
```
- to learn specific git command
```
git --help push
git help push
```

### configuring user information
```
 git config --global user.name "Pranaya Shrestha"
 git config --global user.email "oscurohalcon8@gmail.com"

```

- to see the global configuration 
```
git config --list
```
