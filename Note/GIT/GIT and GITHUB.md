- github is a cloudbase service thet helps developers store and manage their code as well as track and control changes to their code
-  github remote repository to our code base

### cloning the gitrepo
`git clone -b main <link of repo>` to clone the repo 

### pulling from the git
- `git pull` can be used to pull the repo from the github

### commiting and adding
- `git commit -am "message"` this will commit only tracked files
### pushing to the git
- `git push` helps to push the codes committed to the github
