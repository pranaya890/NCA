- Git Repository: directory that contains all the files, history and configuration managed by GIT
- Stages of git
	- Working Directory:  area of live files, also known as Untracked area of GIT
	- Staging Directory: when git starts tracking and saving changes that occur in a file
	- Git directory: also called local repo, .git repo, directory where GIT saves everything

- Remote Repository: GITHub: it is stored on a code hosting service like GITHub or an internal server
- Branch in GIT: way to keep developing and coding a new feature or modification to software and still not affecting the main part of project
