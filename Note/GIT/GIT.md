- free and open source version control system
- Version control system: VCS helps a software team manage change to source code over time
- VCS tracks of every modification to the code in a special kind of database
- VCS helps to rollback to previous version in case of any issue with specific Version

### Types of VCS
- Central Version Control System(CVCS):
	- codes are stored all files and enables team collaboration
	- works on a single repository to which user can directly access a central sever
	![[Pasted image 20260514173939.png]]
	- it is not locally available
- Distributed Version Control System ( DVCS):
	- every contributor has a local copy or clone of main repository
	- user can change and commit local Repo without interference
	- user can update the local repo from central server
	- user can update central  server with updated one
	![[Pasted image 20260514174230.png]]
	- operations are fast 
	- new changes can be  done locally without manipulating the central data
