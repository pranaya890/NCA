- we can create a git repo by creating a directory and initializing it by using `git init`

### Git commit
 - `git commit` is a command used to move the files from working directory to staging area
 - `git commit -m " messae"` is a standard format of commiting
### Git status
- `git status` is a command which informs us about the status of  working directory and staging area
### Git add
- `git add filename` is a command used to move a file to staging area
- `git add .` to move all files of the directory

### Git diff
- `git diff` is a command used to see the difference or a change made to a file

### Git log
- `git log` is a command which shows last 10 commits with commit id and meta data
- `git log --author="Pranaya Shrestha" ` filtering logs of author
- `git log --author="email@gmail.com"` filtering using email
