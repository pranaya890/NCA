
## Purpose of Proxy Setup

- Web proxies allow us to route browser or application traffic through tools like:
    
    - Burp Suite
        
    - OWASP Zed Attack Proxy
        
- This enables us to:
    
    - Capture HTTP/HTTPS requests
        
    - Inspect requests and responses
        
    - Modify request data before forwarding
        
    - Replay requests with changes
        
    - Analyze how applications communicate with back-end servers
        
- Essential for understanding application behavior during web penetration testing
    

---

# Pre-Configured Browsers

## Why Pre-Configured Browsers are Useful

- Both Burp and ZAP provide browsers already configured to:
    
    - Route traffic through the proxy automatically
        
    - Trust the proxy CA certificate
        
- Saves time by avoiding manual browser configuration
    
- Best option for:
    
    - Beginners
        
    - Labs
        
    - Quick testing sessions

# Burp Pre-Configured Browser

    - `Open Browser`

- Uses built-in Chromium browser

- HTTPS traffic works correctly because certificates are pre-installed
    
- Ideal for quick web testing without additional setup

# Manual Proxy Setup in Firefox

## Why Manual Setup is Needed

- Sometimes testers prefer using their own browser instead of embedded browsers
    
- Common reasons:
    
    - Existing extensions
        
    - Better customization
        
    - Familiar browsing environment
        
    - Persistent sessions and bookmarks
        

---

## Default Proxy Configuration

Both Burp and ZAP use:

- IP Address:
    

```text
127.0.0.1
```

- Default Port:
    

```text
8080
```

---

## What 127.0.0.1 Means

- Refers to localhost (your own machine)
    
- Browser traffic is redirected to the proxy running locally
    

---

## Important Notes About Ports

- If port 8080 is already in use:
    
    - Proxy listener will fail to start
        
    - Error messages may appear
        
- Any unused port can be configured manually
    

---

# Changing Proxy Listening Port

## Burp Suite

Navigate to:

- `Proxy > Proxy Settings > Proxy Listeners`
    

---

## ZAP

Navigate to:

- `Tools > Options > Network > Local Servers/Proxies`
    

>[!Tip]
> In case we wanted to serve the web proxy on a different port, we can do that in Burp under (`Proxy>Proxy settings>Proxy listeners`), or in ZAP under (`Tools>Options>Network>Local Servers/Proxies`). In both cases, we must ensure that the proxy configured in Firefox uses the same port.

## Important Requirement

- Firefox proxy settings must match the same port configured in Burp or ZAP
    
- Mismatched ports prevent traffic interception
    

---

# FoxyProxy Extension

## What is FoxyProxy

- FoxyProxy is a Firefox extension used to quickly switch proxy configurations
    
- Prevents manually changing browser proxy settings every time
    

---

## Advantages of FoxyProxy

- Fast proxy switching
    
- Multiple proxy profiles support
    
- Easy enable/disable functionality
    
- Useful when switching between:
    
    - Burp
        
    - ZAP
        
    - Normal browsing
        

---

## Installing FoxyProxy

- Install from Firefox Extensions/Add-ons page
    
- Pre-installed on PwnBox environments
    

---

## Configuring FoxyProxy

### Steps

1. Click FoxyProxy icon
    
2. Open:
    
    - `Options`
        
3. Click:
    
    - `Add`
        
4. Configure:
    
    - IP Address:
        

```text
127.0.0.1
```

- Port:
    

```text
8080
```

- Name:
    
    - Burp or ZAP
        

5. Save configuration
    

---

## Enabling Proxy

- Click FoxyProxy icon
    
- Select:
    
    - Burp
        
    - ZAP
        
- Firefox traffic will now route through the selected proxy
    

---

# Installing CA Certificates

## Why CA Certificates are Important

- HTTPS traffic is encrypted
    
- Without installing proxy CA certificates:
    
    - HTTPS interception may fail
        
    - Browser security warnings will appear repeatedly
        
- Certificates allow the proxy to decrypt and inspect HTTPS traffic safely during testing
    

---

# Installing Burp Certificate

## Downloading Burp CA Certificate

After enabling Burp proxy:

- Browse to:
    

```text
http://burp
```

- Click:
    
    - `CA Certificate`
        
- Download the certificate file
    

---

# Installing ZAP Certificate

## Exporting ZAP Certificate

Navigate to:

- `Tools > Options > Network > Server Certificates`
    

---

## Options Available

- Save existing certificate
    
- Generate new certificate
    
- Import certificate
    

---

## Generating New Certificates

- ZAP allows creating custom CA certificates
    
- Useful for:
    
    - Fresh environments
        
    - Custom testing setups
        

---

# Importing Certificates into Firefox

## Opening Certificate Manager

Browse to:

```text
about:preferences#privacy
```

---

## Steps to Import Certificate

1. Scroll to:
    
    - Certificates section
        
2. Click:
    
    - `View Certificates`
        
3. Open:
    
    - `Authorities` tab
        
4. Click:
    
    - `Import`
        
5. Select downloaded CA certificate
    

---

# Trust Settings

## Required Trust Options

After importing the certificate:

- Enable:
    
    - `Trust this CA to identify websites`
        
    - `Trust this CA to identify email users`
        

---

## Why Trust Must Be Enabled

- Allows Firefox to trust HTTPS certificates generated by Burp/ZAP
    
- Prevents SSL/TLS warnings during interception
    

---

# Final Result

Once:

- Proxy is configured
    
- FoxyProxy is enabled
    
- CA certificate is installed
    

Then:

- All browser traffic routes through Burp or ZAP
    
- HTTP and HTTPS requests can be:
    
    - Captured
        
    - Modified
        
    - Replayed
        
    - Analyzed
        

---

# Key Takeaways

- Proxy setup is essential for intercepting and analyzing web traffic
    
- Pre-configured browsers simplify setup for beginners
    
- Firefox can be manually configured using FoxyProxy
    
- Both Burp and ZAP usually listen on port 8080
    
- Installing CA certificates is required for proper HTTPS interception
    
- Proper proxy and certificate configuration enables full web application traffic analysis
