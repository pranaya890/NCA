## Purpose

- Extensions/add-ons expand Burp and ZAP functionality.
    
- Community-created plugins add:
    
    - New scanners
        
    - Encoders/decoders
        
    - Fuzzing payloads
        
    - Automation tools
        
    - JavaScript analyzers
        
    - Vulnerability checks
        

# Burp Extensions (BApp Store)

## Accessing BApp Store

Go to:

```text
Extensions > BApp Store
```

### Features

- Install extensions directly inside Burp
    
- Sort by:
    
    - Popularity
        
    - Rating
        
    - Last updated
        
- Some extensions require:
    
    - Jython
        
    - Java
        
    - Other dependencies
        

## Example Extension: Decoder Improved

### Installation

- Search for `Decoder Improved`
    
- Click `Install`
    

### Features

- Extra encoders/decoders
    
- More hashing options
    
- Better text handling
    
- Unicode support
    
- Hex editor
    

### Example

Hash text with:

```text
Hash With > MD5
```

# Example: Installing FuzzDB Wordlists

## Install

- `FuzzDB Files`
    
- `FuzzDB Offensive`
    

## Benefits

Adds payloads for:

- Command Injection
    
- SQL Injection
    
- XSS
    
- LFI/RFI
    
- Path Traversal
    
- Authentication attacks
    

## Usage

During fuzzing:

```text
File Fuzzers > fuzzdb > attack > os-cmd-execution
```

### Example Payloads

```bash
;id
&& whoami
| cat /etc/passwd
/usr/bin/id
```

## Why Useful

- Faster vulnerability discovery
    
- Better WAF bypass payloads
    
- Large prebuilt payload database
    

# Burp vs ZAP Extensions

|Feature|Burp BApp Store|ZAP Marketplace|
|---|---|---|
|Cost|Some Pro-only|Fully free|
|Extension Count|Very large|Large|
|Stability|Usually polished|Mixed|
|Advanced Research Plugins|Excellent|Good|
|Wordlists Included|Limited|Better built-in|
|Enterprise Usage|Very common|Common|

# Key Takeaways

- Extensions dramatically improve testing efficiency.
    
- Burp extensions are stronger for advanced enterprise testing.
    
- ZAP add-ons are excellent for free/open-source workflows.
    
- Install only what you actually use to keep tools lightweight.
