# Burp Suite Setup

## Downloading Burp Suite

- Burp can be downloaded from the official download page provided by [PortSwigger](https://portswigger.net/burp/communitydownload?utm_source=chatgpt.com)
    
- Separate installers are available for:
    
    - Windows
        
    - Linux
        
    - macOS
        
- Installation process is generally straightforward and guided through a setup wizard
    

---

## Launching Burp Suite

Burp can be started in multiple ways:

- From terminal:
    

```bash
burpsuite
```

- Using the JAR file:
    

```bash
java -jar </path/to/burpsuite.jar>
```

- By double-clicking the JAR file if Java is installed
    

---

## Java Runtime Environment (JRE)

- Both Burp and ZAP require Java Runtime Environment (JRE) to run
    
- Most installers include JRE automatically
    
- If Java is missing, it must be installed manually before running the tools
    
- JAR files provide cross-platform compatibility because they run anywhere Java is available
    

---

## Creating a Burp Project

When Burp starts, it prompts for project setup.

### Community Edition

- Only supports temporary projects
    
- Progress cannot be permanently saved
    
- Suitable for:
    
    - Small labs
        
    - Practice environments
        
    - Short-term testing sessions
        

---

### Professional/Enterprise Editions

Additional options become available:

- Create a new project on disk
    
- Open an existing project
    
- Save scan progress and configurations
    
- Useful for:
    
    - Large web applications
        
    - Long-term engagements
        
    - Active vulnerability scans
        

---

## Recommended Beginner Setup

For beginners or small labs:

- Select:
    
    - **Temporary Project**
        
    - **Use Burp Defaults**
        
- Then click:
    
    - **Start Burp**
        
- Default settings are enough for most basic web pentesting tasks
    

---

## Burp Configuration Files

- Burp allows custom configuration loading
    
- Useful for:
    
    - Custom proxy settings
        
    - Extensions
        
    - Scanner configurations
        
    - Interface preferences
        
- Advanced users often create reusable configurations for different engagements
    

---

# ZAP Setup

## Downloading ZAP

- OWASP Zed Attack Proxy can be downloaded from the official site:
    
    - [OWASP ZAP Download Page](https://www.zaproxy.org/download/?utm_source=chatgpt.com)
        
- Available for:
    
    - Windows
        
    - Linux
        
    - macOS
        
- Also available as a cross-platform JAR file
    

---

## Launching ZAP

ZAP can be started using:

- Terminal:
    

```bash
zaproxy
```

- Java JAR:
    

```bash
java -jar zap.jar
```

- Application launcher/menu
    

---

## ZAP Session Persistence

When ZAP starts, it asks whether to persist sessions.

### Options Available

- Save session automatically
    
- Specify custom save location
    
- Use temporary session
    

---

## Recommended Beginner Choice

- Choose:
    
    - **No, I do not want to persist this session at this moment**
        
- Best for:
    
    - Labs
        
    - HTB exercises
        
    - Temporary testing environments
        

---

# Burp vs ZAP Setup Differences

## Burp Suite

- Community version limits project persistence
    
- More polished setup workflow
    
- Some advanced features locked behind paid versions
    

---

## ZAP

- Free and open-source
    
- Allows session persistence without payment
    
- No major feature restrictions for free users
    

---

# Dark Theme Configuration

## Burp Suite Dark Mode

Navigate to:

- `Burp > Settings > User Interface > Display`
    
- Set Theme to:
    
    - `Dark`
        

---

## ZAP Dark Mode

Navigate to:

- `Tools > Options > Display`
    
- Set Look and Feel to:
    
    - `Flat Dark`
        

---

# Key Takeaways

- Both Burp and ZAP are cross-platform web proxy tools used for web penetration testing
    
- Both rely on Java Runtime Environment (JRE)
    
- Temporary projects are usually enough for learning and short labs
    
- Burp Community Edition has some limitations compared to Burp Pro
    
- ZAP provides a fully free and open-source alternative with many advanced features
    
- Custom configurations and session persistence become more useful during large or long-term pentests
