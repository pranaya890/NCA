
## Spider

- ZAP Spider is similar to Burp Crawler.
    
- It builds a site map by following links and discovering pages.
    
- To start:
    
    - Go to History tab
        
    - Right-click a request
        
    - Select `Attack > Spider`
        
- You can also start it from the HUD browser using the Spider button.
    

### Scope

- ZAP may ask to add the site to scope before scanning.
    
- Scope defines which URLs ZAP will test.
    
- Multiple targets can be added to scope.
    

### Results

- Progress is shown in:
    
    - HUD
        
    - Spider tab
        
    - Main ZAP UI
        
- Discovered URLs appear in the `Sites` tree.
    

### Ajax Spider

- Ajax Spider detects JavaScript/AJAX-loaded links.
    
- Useful for modern dynamic applications.
    
- Usually finds more endpoints than normal Spider.
    
- Takes longer to complete.
    

## Passive Scanner

- Runs automatically while Spider browses pages.
    
- Does not send malicious requests.
    
- Looks for issues like:
    
    - Missing security headers
        
    - DOM-based XSS
        
    - Misconfigurations
        

### Alerts

- Alerts appear in:
    
    - Left pane (current page)
        
    - Right pane (entire application)
        
    - Alerts tab
        

### Example Findings

- Missing `X-Frame-Options`
    
- Missing `HttpOnly`
    
- CSP issues
    

## Active Scanner

- Performs real attacks against discovered endpoints.
    
- Starts after Spider builds the site tree.
    
- Automatically fuzzes:
    
    - Parameters
        
    - Forms
        
    - URLs
        
    - Inputs
        

### Detects Vulnerabilities Like

- SQL Injection
    
- Command Injection
    
- XSS
    
- File Inclusion
    
- Authentication flaws
    

### Scan Progress

- Progress shown in:
    
    - HUD
        
    - Active Scan tab
        
    - Request logs
        

### Example High Alert

- Remote OS Command Injection
    
- Example payload:
    

```http
127.0.0.1&cat /etc/passwd&
```

### Alert Details

- Risk level
    
- Confidence level
    
- Attack payload
    
- Evidence
    
- Request/response used to detect vulnerability
    

## Viewing Requests

- Click alert URL to inspect:
    
    - Request
        
    - Response
        
- Replay using:
    
    - ZAP HUD
        
    - Request Editor
        
    - Replay in Browser
        
    - Replay in Console
        

## Reporting

Generate reports from:

```text
Report > Generate HTML Report
```

### Supported Formats

- HTML
    
- XML
    
- Markdown
    

### Report Includes

- Vulnerability summary
    
- Risk levels
    
- Evidence
    
- URLs affected
    
- Remediation guidance
    

### Example Summary

- 1 High
    
- 3 Medium
    
- 8 Low
    
- 6 Informational
    

## Key Difference vs Burp Scanner

|Feature|ZAP Scanner|Burp Scanner|
|---|---|---|
|Cost|Free|Pro only|
|Spider|Yes|Yes|
|Passive Scan|Yes|Yes|
|Active Scan|Yes|Yes|
|AJAX Spider|Yes|Limited equivalent|
|Speed|Fast|Fast|
|Enterprise Features|Fewer|More advanced|

## Best Use Cases

- Free professional web scanning
    
- Learning web pentesting
    
- Automated vulnerability discovery
    
- Dynamic web application testing
    
- AJAX-heavy applications
