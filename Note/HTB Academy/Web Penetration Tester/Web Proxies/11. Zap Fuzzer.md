## What is ZAP Fuzzer

- OWASP Zed Attack Proxy includes a built-in fuzzing tool called:
    

```text
ZAP Fuzzer
```

- Used for:
    
    - Web fuzzing
        
    - Directory discovery
        
    - Parameter testing
        
    - Enumeration
        
    - Brute-forcing
        

# ZAP Fuzzer vs Burp Intruder

## Main Advantage

- No speed throttling
    
- Faster than Burp Community Intruder
    

## Limitation

- Missing some advanced Intruder features
    
- Less flexible payload customization
    

# Basic Fuzzing Workflow

- Capture a request
    
- Define fuzz location
    
- Configure payloads
    
- Add processors
    
- Configure options
    
- Start fuzzing attack
    

# Capturing a Request

## Example Target

```text
http://SERVER_IP:PORT/test/
```

## Purpose

- The word:
    

```text
test
```

will later become the fuzzing location

# Sending Request to Fuzzer

## Steps

- Open Proxy History
    
- Right-click request
    
- Select:
    

```text
Attack > Fuzz
```

# Main Fuzzer Components

- Fuzz Location
    
- Payloads
    
- Processors
    
- Options
    

# Fuzz Locations

## Purpose

- Defines where payloads will be inserted
    
- Equivalent to Burp Intruder payload positions
    

# Adding a Fuzz Location

## Steps

- Highlight desired word
    
- Click:
    

```text
Add
```

## Example

```http
GET /test/ HTTP/1.1
```

becomes:

```http
GET /FUZZ/ HTTP/1.1
```

# Payloads

## Purpose

- Defines the wordlist or payload source used during fuzzing
    

# Common Payload Types

## File

- Load custom wordlists from files
    

## File Fuzzers

- Uses built-in ZAP wordlists
    

## Numberzz

- Generates numeric sequences automatically
    

# Built-In Wordlists

## Advantage

- ZAP includes built-in fuzzing databases
    
- No need to manually download wordlists
    

# Example Wordlist

```text
dirbuster/directory-list-1.0.txt
```

# Example Payload Entries

```text
cgi-bin
.git
.svn
```

# Payload Processors

## Purpose

- Modify payloads before sending requests
    

# Common Processors

- Base64 Encode/Decode
    
- URL Encode/Decode
    
- MD5 Hash
    
- SHA-1/256/512 Hash
    
- Prefix String
    
- Postfix String
    
- Script
    

# URL Encode Processor

## Purpose

- Properly encodes special characters
    
- Prevents malformed requests
    
- Helps avoid server errors
    

# Preview Feature

## Generate Preview

- Shows final payload output before attack starts
    
- Useful for verifying transformations
    

# Fuzzer Options

## Purpose

- Configure attack behavior and performance
    

# Concurrent Threads

## Example Setting

```text
20 concurrent threads
```

## Effect

- Faster fuzzing
    
- Multiple requests sent simultaneously
    

# Important Consideration

- Higher thread count increases:
    
    - CPU usage
        
    - Network usage
        
    - Server load
        

# Fuzzing Strategies

## Depth First

- Tests all payloads on one position before moving to next
    

### Example

```text
Try every password for one user before testing another user
```

# Breadth First

- Tests same payload across all positions before next payload
    

### Example

```text
Try one password against all users before moving to next password
```

# Starting the Attack

## Launch

- Click:
    

```text
Start Fuzzer
```

# Analyzing Results

## Useful Columns

- HTTP Response Code
    
- Response Size
    
- RTT (Round Trip Time)
    
- Payload Used
    

# Sorting Results

## Common Sorting Method

- Sort by:
    

```text
HTTP Response Code
```

# Example Successful Result

## Payload

```text
skills
```

## Response

```text
200 OK
```

## Meaning

- Directory exists:
    

```text
/skills/
```

# Viewing Request & Response

## Benefits

- Inspect returned content
    
- Verify successful hits
    
- Analyze server behavior
    

# Important Indicators

## HTTP Code

- `200` usually means success
    
- `404` usually means missing page
    
- `403` may indicate restricted resource
    

# Response Size

## Purpose

- Detect different page behavior
    
- Useful when response codes remain identical
    

# RTT (Round Trip Time)

## Purpose

- Detect timing differences
    
- Useful for:
    
    - Time-based SQL injection
        
    - Delayed responses
        
    - Blind vulnerability testing
        

# Advantages of ZAP Fuzzer

- Completely free
    
- No rate limiting
    
- Built-in wordlists
    
- Fast concurrent scanning
    
- Easy payload processing
    
- Good for large fuzzing attacks
    

# Limitations Compared to Burp Intruder

- Fewer advanced payload options
    
- Less flexible attack customization
    
- Simpler payload handling system
    

# Key Takeaways

- ZAP Fuzzer is a fast built-in fuzzing tool
    
- Uses fuzz locations to insert payloads
    
- Supports built-in and custom wordlists
    
- Payload processors modify payloads automatically
    
- Concurrent threads significantly improve speed
    
- Response codes, size, and timing help identify valid results
    
- Excellent free alternative to Burp Intruder for web fuzzing
