## What is Burp Scanner

- Burp Suite includes a built-in vulnerability scanner called:
    

```text
Burp Scanner
```

- Used for:
    
    - Web vulnerability scanning
        
    - Website crawling
        
    - Passive analysis
        
    - Active exploitation testing
        
    - JavaScript analysis
        
    - Automated vulnerability discovery
        

# Availability

- Burp Scanner is:
    

```text
Pro-only feature
```

- Not available in:
    

```text
Burp Community Edition
```

# Passive Scanner

## What is Passive Scanning

- Analyzes already visited pages
    
- Does not send additional requests
    

# Purpose

- Quickly identify:
    
    - Missing security headers
        
    - DOM-based XSS indicators
        
    - Cookie issues
        
    - Clickjacking risks
        

# Characteristics

- Low risk
    
- Fast
    
- Non-intrusive
    

# Important Limitation

- Cannot fully verify vulnerabilities
    
- Only suggests potential issues
    

# Confidence Levels

- Certain
    
- Firm
    
- Tentative
    

# Severity Levels

- High
    
- Medium
    
- Low
    
- Information
    

# Common Passive Findings

## Example Vulnerabilities

- Missing HttpOnly flag
    
- Missing security headers
    
- Clickjacking exposure
    
- Information leakage
    

# Active Scanner

## What is Active Scanning

- Performs real vulnerability testing
    
- Sends crafted payloads
    
- Verifies exploitable issues
    

# Active Scan Workflow

## Step 1

- Crawl website
    

## Step 2

- Perform directory/content discovery
    

## Step 3

- Run passive analysis
    

## Step 4

- Verify identified vulnerabilities
    

## Step 5

- Analyze JavaScript
    

## Step 6

- Fuzz insertion points and parameters

- Organized vulnerability tracking
    
- Useful remediation references
    
- Helpful appendix material
    

# Important Pentesting Practice

- Never submit raw scanner reports directly as final deliverables
    
- Always:
    
    - Validate findings manually
        
    - Remove false positives
        
    - Add analyst explanations
        
    - Include business impact
        
    - Provide proper remediation guidance
        

# Burp Scanner Strengths

- Enterprise-grade vulnerability detection
    
- Advanced crawling engine
    
- Strong active scanning capabilities
    
- Frequent vulnerability updates
    
- Excellent reporting system
    
- Deep JavaScript analysis
    

# Burp Scanner Limitations

- Requires Burp Pro license
    
- Active scans can be noisy
    
- Long scans consume significant resources
    
- May generate false positives
    
- Aggressive scans may impact fragile applications
    

# Key Takeaways

- Burp Scanner combines crawling and vulnerability testing
    
- Passive scans analyze existing traffic safely
    
- Active scans aggressively verify vulnerabilities
    
- Scope management is critical for safe scanning
    
- High severity + high confidence findings deserve priority
    
- Reports should supplement manual pentest findings, not replace them
