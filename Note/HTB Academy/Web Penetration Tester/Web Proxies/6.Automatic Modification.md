
## Purpose of Automatic Modification

- Web proxies can automatically modify:
    - Outgoing HTTP requests
    - Incoming HTTP responses
- Useful when repetitive changes are needed during testing
- Saves time by avoiding manual interception and editing every request/response
- Commonly used to:
    - Change headers
    - Bypass client-side restrictions
    - Modify HTML responses automatically
    - Test filters and validation mechanisms

# Automatic Request Modification

## What It Does

- Automatically searches for specific text in HTTP requests
    
- Replaces matched content with custom values
    
- Can modify:
    
    - Request headers
        
    - Request body
        
    - Cookies
        
    - Parameters
        

# Burp Match and Replace

## Accessing Match and Replace

- In Burp Suite navigate to:
    
    - `Proxy > Proxy Settings > HTTP Match and Replace Rules`
        

## Example Goal

- Replace browser User-Agent with:
    

```text
HackTheBox Agent 1.0
```

## Rule Configuration

### Type

```text
Request header
```

- Because User-Agent exists in request headers
    

### Match

```text
^User-Agent.*$
```

- Regex pattern matching the entire User-Agent line
    

### Replace

```text
User-Agent: HackTheBox Agent 1.0
```

### Regex Match

```text
True
```

- Regex needed because actual User-Agent string may vary
    

# Result

- Every outgoing request automatically uses:
    

```http
User-Agent: HackTheBox Agent 1.0
```

- Useful for:
    
    - Bypassing User-Agent filters
        
    - Hiding browser fingerprints
        
    - Testing server behavior with custom headers
        

# Verifying Changes

- Enable interception
    
- Visit any website using Burp browser
    
- Inspect intercepted request
    
- Modified User-Agent should appear automatically
    

# ZAP Replacer

## Accessing Replacer

- In OWASP Zed Attack Proxy:
    
    - Press:
        

```text
CTRL + R
```

- Or navigate through ZAP options menu
    

# Replacer Rule Example

## Description

```text
HTB User-Agent
```

## Match Type

```text
Request Header
```

## Match String

```text
User-Agent
```

## Replacement String

```text
HackTheBox Agent 1.0
```

## Enable

```text
True
```

# ZAP Initiators

- ZAP allows selecting where replacement rules apply
    
- Default option:
    

```text
Apply to all HTTP(S) messages
```

- Can limit rules to specific tools or requests if needed
    

# Regex Support in ZAP

- ZAP also supports regex-based matching
    
- Similar functionality to Burp Match and Replace
    
- Useful when exact values are unknown
    

# Automatic Response Modification

## Purpose

- Automatically modify server responses before rendering in the browser
    
- Makes front-end bypasses persistent across refreshes
    
- Removes need for manual response editing
    

# Example Use Case

## Original HTML

```html
<input type="number" maxlength="3">
```

## Problem

- Only numeric input allowed
    
- Input length restricted
    
- Prevents longer payloads
    

# Automatic Response Rule in Burp

## Accessing Rules

- Navigate to:
    
    - `Proxy > Options > Match and Replace`
        

## Rule Configuration

### Type

```text
Response body
```

### Match

```text
type="number"
```

### Replace

```text
type="text"
```

### Regex Match

```text
False
```

# Additional Rule

- Change:
    

```html
maxlength="3"
```

to:

```html
maxlength="100"
```

# Result

- Browser permanently receives modified HTML
    
- Input field now:
    
    - Accepts any character
        
    - Supports longer payloads
        
- Changes persist after page refresh
    

# Benefits of Automatic Response Modification

- Faster testing workflow
    
- Persistent client-side bypasses
    
- No repeated manual interception
    
- Useful for:
    
    - Command injection testing
        
    - XSS testing
        
    - Hidden field manipulation
        
    - Form modification
        

# Practical Impact

- Payloads can be entered directly through browser UI
    
- Easier interaction with vulnerable applications
    
- Simplifies repeated exploitation attempts
    

# Key Takeaways

- Automatic modification applies rules to requests/responses without manual editing
    
- Burp uses Match and Replace rules
    
- ZAP uses Replacer rules
    
- Request modification commonly changes headers like User-Agent
    
- Response modification can bypass front-end restrictions permanently
    
- Automatic modifications improve efficiency during web application penetration testing
