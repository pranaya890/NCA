## Purpose of Encoding and Decoding

- Web applications often encode data before sending or storing it
- During web penetration testing, we frequently need to:
    - Decode application data
        
    - Modify decoded values
        
    - Re-encode data before sending requests
        
- Incorrect encoding may:
    
    - Break requests
        
    - Cause server errors
        
    - Change request behavior
        

# URL Encoding

## What is URL Encoding

- URL encoding converts special characters into a safe format for HTTP transmission
    
- Special characters may otherwise be interpreted incorrectly by servers or browsers
    

## Important Characters to Encode

### Spaces

- May terminate request data unexpectedly
    

### &

- Interpreted as a parameter separator
    

- Interpreted as a URL fragment identifier
    

# Common URL Encoded Characters

|Character|Encoded Value|
|---|---|
|Space|`%20`|
|;|`%3B`|
|&|`%26`|
|#|`%23`|
|=|`%3D`|

# URL Encoding in Burp Suite

## Encoding Selected Text

- In Burp Suite:
    
    - Highlight text
        
    - Right-click
        
    - Select:
        
        - `Convert Selection > URL > URL-encode key characters`
            

## Shortcut

```text
CTRL + U
```

## Automatic URL Encoding

- Burp can automatically encode text while typing
    
- Useful when crafting payloads manually
    

# URL Encoding in ZAP

## Automatic Encoding

- OWASP Zed Attack Proxy automatically URL-encodes request data before sending requests
    
- Encoding may happen in the background without being visibly shown
    

# Other URL Encoding Types

- Full URL encoding
    
- Unicode URL encoding
    
- Helpful for payloads containing many special characters
    

# Decoding

## Why Decoding Matters

- Web applications frequently encode:
    
    - Cookies
        
    - Tokens
        
    - Parameters
        
    - Session data
        
- Decoding allows us to inspect the original content
    

## Common Encoding Types

- HTML encoding
    
- Unicode encoding
    
- Base64 encoding
    
- ASCII hex encoding

    - `Decoder` tab

- Encode and decode text quickly

# Base64 Example

## Encoded Cookie

```text
eyJ1c2VybmFtZSI6Imd1ZXN0IiwgImlzX2FkbWluIjpmYWxzZX0=
```

# Decoding the Cookie

## Decoded Value

```json
{"username":"guest", "is_admin":false}
```

## Meaning

- Cookie contains JSON data
    
- User currently:
    
    - username = guest
        
    - is_admin = false
        

# Manipulating Decoded Data

## Modified Value

```json
{"username":"admin", "is_admin":true}
```

## Goal

- Test whether application trusts client-side cookie values
    
- Attempt privilege escalation
    

# Re-encoding the Modified Data

## Base64 Encoded Result

```text
eyJ1c2VybmFtZSI6ImFkbWluIiwgImlzX2FkbWluIjp0cnVlfQ==
```

# Using Modified Encoded Data

- Replace original cookie value with modified encoded string
    
- Send request using:
    
    - Burp Repeater
        
    - ZAP Request Editor

- ZAP allows creating personalized encoding tabs
    
- Can display multiple encoding formats simultaneously
    

## Useful For

- Frequently used encodings
    
- Faster workflow customization
    
- Multi-format analysis
    

# Practical Uses of Encoding/Decoding

## Cookie Manipulation

- Modify privilege values
    
- Test authentication logic
    

## Payload Preparation

- Encode payloads before sending requests
    

## Token Analysis

- Decode JWTs or encoded session tokens
    

## Request Crafting

- Properly format special characters in HTTP requests
    

# Importance in Web Pentesting

- Many applications rely heavily on encoded data
    
- Understanding encoding is critical for:
    
    - Request manipulation
        
    - Exploitation
        
    - Authentication testing
        
    - Parameter tampering
        

# Key Takeaways

- URL encoding ensures special characters are transmitted safely
    
- Burp and ZAP both provide built-in encoding/decoding tools
    
- Base64 is commonly used in cookies and tokens
    
- Encoded data can often be modified and re-encoded during testing
    
- Proper encoding is essential for crafting valid HTTP requests
    
- Encoding and decoding are fundamental skills in web application penetration testing
