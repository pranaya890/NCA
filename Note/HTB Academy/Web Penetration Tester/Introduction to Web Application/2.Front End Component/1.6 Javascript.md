
- `JavaScript` is one of the most widely used programming languages
- mainly used for:
  - web development
  - mobile development

- JavaScript is commonly executed:
  - on the frontend within the browser
- backend implementations also exist:
  - example:
    - `NodeJS`

- while:
  - `HTML` controls structure/content
  - `CSS` controls styling/design
- `JavaScript` controls:
  - functionality
  - interactivity
  - dynamic behavior

- without JavaScript:
  - webpages are mostly static
  - interactive features are limited

- JavaScript code is loaded using the `<script>` tag:
```html
<script type="text/javascript">
..JavaScript code..
</script>
````

- external JavaScript files can be loaded using:
    

```html
<script src="./script.js"></script>
```

- example JavaScript code:
    

```javascript
document.getElementById("button1").innerHTML = "Changed Text!";
```

- the above code:
    
    - selects an HTML element by ID
        
    - changes its displayed content
        
- JavaScript is used for:
    
    - updating webpages dynamically
        
    - processing user input
        
    - real-time content updates
        
    - automating frontend processes
        
    - interactive functionality
        
- JavaScript can send and retrieve data from backend servers using:
    
    - HTTP requests
        
    - `Ajax`
        
- JavaScript is commonly combined with `CSS` to create:
    
    - advanced animations
        
    - interactive visual effects
        
- modern browsers contain:
    
    - JavaScript engines
        
- these engines execute JavaScript directly on the client-side
    
- benefits:
    
    - fast execution
        
    - reduced dependency on backend processing
        
- online platforms such as `JSFiddle` can be used to:
    
    - test JavaScript
        
    - test HTML/CSS integration
        
    - save code snippets
        

### JavaScript Frameworks

- pure JavaScript development can become inefficient for large applications
    
- JavaScript frameworks simplify:
    
    - development
        
    - code reuse
        
    - implementation of advanced functionality
        
- frameworks provide:
    
    - reusable libraries
        
    - dynamic HTML rendering
        
    - built-in functionality
        
        - user login
            
        - user registration
            
        - interactive components
            
- frameworks either:
    
    - use JavaScript directly
        
    - compile into JavaScript

- [Vue](https://www.w3schools.com/whatis/whatis_vue.asp)
