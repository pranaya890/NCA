
- `CSS` (Cascading Style Sheets) is a stylesheet language used with `HTML`
- used to:
  - format HTML elements
  - control webpage styling and appearance

- CSS has multiple versions
- newer versions introduce:
  - new styling capabilities
  - advanced features
- browsers are updated to support new CSS features

- CSS defines styles for:
  - HTML elements
  - classes
  - IDs

- common style properties include:
  - font family
  - font size
  - background color
  - text color
  - alignment
  - height
  - position
  - border
  - margin
  - padding

- basic CSS syntax:
``` css
element {
  property: value;
}
```
- example
```css
  body {
  background-color: black;
}

h1 {
  color: white;
  text-align: center;
}

p {
  font-family: helvetica;
  font-size: 10px;
}
```


- unique IDs and class names in HTML allow:
    - targeting elements in CSS
    - manipulation through JavaScript
- CSS can create:
    - visually appealing webpages
    - advanced animations
    - responsive layouts
- animation-related CSS properties include:
    - `@keyframes`
    - `animation`
    - `animation-duration`
    - `animation-direction`
- CSS is often combined with `JavaScript` to:
    - dynamically modify page styles
    - create animations
    - respond to keyboard/mouse interactions
    - perform visual calculations
- proper use of HTML + CSS + JavaScript can create:
    - visually stunning interfaces
    - user-friendly web applications
    - interactive user experiences
- CSS can also be used with:
    - `XML`
    - `SVG`
    - mobile application UI development

### CSS Frameworks

- CSS frameworks provide:
    - prebuilt stylesheets
    - reusable design components
    - faster web development
- frameworks help:
    - reduce manual styling work
    - improve development efficiency
    - optimize designs for web applications
- many frameworks are designed to integrate with `JavaScript`
- common CSS frameworks:
    -  [Bootstrap](https://www.w3schools.com/bootstrap4/)
    - [SASS](https://sass-lang.com/)
    -  [Foundation](https://en.wikipedia.org/wiki/Foundation_\(framework\))
    -  [Bulma](https://bulma.io/)
    -  [Pure](https://purecss.io/)
