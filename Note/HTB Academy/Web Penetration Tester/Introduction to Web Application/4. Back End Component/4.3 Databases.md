# Relational (SQL) Databases

- relational databases store data in:
  - tables
  - rows
  - columns

- tables can contain:
  - unique keys
  - relationships with other tables

- example tables:
  - `users`
    - `id`
    - `username`
    - `first_name`
    - `last_name`
  - `posts`
    - `id`
    - `user_id`
    - `date`
    - `content`

- relationships are created by linking keys between tables
- example:
  - `users.id` linked to `posts.user_id`

- benefits of relationships:
  - avoid duplicate data
  - simplify data retrieval
  - improve organization

- tables may contain:
  - multiple keys
  - relationships to multiple tables

- example:
  - `posts.id` linked to a `comments` table

- relationship structure between database tables is called:
  - `Schema`

# Non-relational (NoSQL) Databases

- NoSQL databases do not use:
  - tables
  - rows
  - columns
  - schemas
  - primary keys
  - relationships

- NoSQL databases store data using different storage models depending on data type

- advantages:
  - high scalability
  - flexibility
  - ideal for unstructured or semi-structured data


# Common NoSQL Storage Models

- `Key-Value`
- `Document-Based`
- `Wide-Column`
- `Graph`

- each model stores data differently

# Key-Value Model

- stores data as:
  - key-value pairs
- data commonly stored using:
  - `JSON`
  - `XML`


![[Pasted image 20260518213226.png]]



- example JSON structure:
```json
{
  "100001": {
    "date": "01-01-2021",
    "content": "Welcome to this web application."
  }
}
````

- similar to:
    
    - dictionaries/maps in programming languages
        
    - example:
        

```python
{'key':'value'}
```

# Document-Based Model

- stores data in:
    
    - complex JSON objects
        
- each object contains:
    
    - metadata
        
    - structured document data

# Databases in Web Applications

- modern web frameworks easily integrate with databases
    
- databases must first be:
    
    - installed
        
    - configured
        
    - running on backend servers
        
- example PHP connection to MySQL:
    

```php
$conn = new mysqli("localhost", "user", "pass");
```

- creating a database:
    

```php
$sql = "CREATE DATABASE database1";
$conn->query($sql);
```

- querying a database:
    

```php
$query = "select * from table_1";
$result = $conn->query($query);
```

- web applications often use user input in database queries
    
- example:
    

```php
$searchInput =  $_POST['findUser'];
$query = "select * from users where name like '%$searchInput%'";
```

- results can be displayed to users:
    

```php
while($row = $result->fetch_assoc() ){
    echo $row["name"]."<br>";
}
```

- insecure database code may lead to vulnerabilities such as:
    
    - `SQL Injection`
