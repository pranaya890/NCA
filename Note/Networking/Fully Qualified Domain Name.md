- sometimes called as absolute domain
- is a domain name that specifies the exact location in the tree hierarchy of a DNS
- it specifies all domain levels, including the top-level domain and root zone
- FQDN is distinguished by its umambigious DNS zone location in the hierarchy of DNS label
- it can be interpreted in only one way
---
- a FQDN is conventionally written as a list of domain labels seperated using full stop(.)
- top of hierarchy in a FQDN  begins with rightmost labels
