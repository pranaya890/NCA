

Open source OS based on UNIX architecture
Created by Linus Torvalds in 1991 
undergoing development by `Richard Stallman`
Follows monolithic kernel( entire OS runs in a single kernel) design 
core component is kernel

Widely used in servers, cyber security, programming, embedded systems, and ethical hacking 
Examples Kali, Ubuntu, Ubuntu,Debian,Arch etc

Unix based system developed by apple is `macOS`

### Why Linux over Unix?
Free and Open source
Run on a wide range of hardware
customisation, multi-user and modular

### Linux Distribution
Distribution also referred as "distros" 
Operating System built upon Linux kernel
Made for different purposes like powering servers and embedded system, network analysis, vulnerability scanning and exploitation
These distros variation provide unique configuration , software packages and tools
Examples ParrotOS, Kali Linux, BlackArch, Pentoo


### Why Kali Linux?
Kali is one of Linux Distribution
Easy to install and use for beginner
Comes with set of penetration testing tool

### Why hackers use Linux?
Open source
Anyone can inspect, modify and optimise the code
Provides complete control over OS
OS like windows having their internal working hidden Linux is fully transparent allowing hacker and penetration testers to understand exactly how system operates, identify vulnerability of system and customise it according to need
User has full control over system resources, and deep customisation are available
The majority of hacking and penetration tester tools work more efficiently on Linux
Linux is widely regarded as future of computing
Linux being more secure than windows by design with better privilege management, fewer exploitable vulnerabilities and lower malware infection
Offers powerful scripting and automation capabilities with Bash, Python and Perl,  which are used for hackers for  automating attacks.
"Linux isn't just a choice for hackers -- it's a necessity"
