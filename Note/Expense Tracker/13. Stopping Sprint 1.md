
# End of Today's Development Session

From your project root (`PFMS/`), run:

```bash
docker compose down
```

This will:

- ✅ Stop Django
    
- ✅ Stop PostgreSQL
    
- ✅ Stop MongoDB
    
- ✅ Stop Redis
    
- ✅ Stop Celery
    
- ✅ Stop Nginx
    
- ✅ Remove the containers
    

**It will NOT delete your data.**

Your PostgreSQL and MongoDB data remain safe because they are stored in Docker volumes.

---

## Verify Everything Stopped

```bash
docker ps
```

You should see:

```text
CONTAINER ID   IMAGE   COMMAND   CREATED   STATUS   PORTS   NAMES
```

No running containers.

# Next Time You Continue Development

Navigate to your project:

```bash
cd ~/Projects/PFMS
```

(Optional but recommended) Pull any remote changes:

```bash
git pull
```

Start everything:

```bash
docker compose up -d
```

Check that everything is running:

```bash
docker ps
```

Expected:

```text
pfms-postgres
pfms-mongodb
pfms-redis
pfms-django
pfms-celery
pfms-nginx
```

Open your application:

```
http://localhost
```

or

```
http://localhost/admin
```

You're ready to code.

# During Development

Useful commands you'll use frequently:

### View logs

```bash
docker compose logs -f django
```

```bash
docker compose logs -f celery
```

```bash
docker compose logs -f nginx
```

---

### Enter the Django container

```bash
docker compose exec django bash
```

---

### Run Django commands

```bash
docker compose exec django python manage.py makemigrations
```

```bash
docker compose exec django python manage.py migrate
```

```bash
docker compose exec django python manage.py createsuperuser
```

```bash
docker compose exec django python manage.py shell
```

---

### Restart a single service

For example, only Django:

```bash
docker compose restart django
```

Or Celery:

```bash
docker compose restart celery
```

No need to restart everything unless necessary.

---

# If You Change Dependencies

For example, you edit `backend/requirements/base.txt`:

```bash
docker compose build
docker compose up -d
```

If you only change Python code, **you don't need to rebuild** because your `backend/` directory is mounted as a volume.

---

# If You Change the Dockerfile

Rebuild:

```bash
docker compose build
docker compose up -d
```

---

# If You Change `docker-compose.yml`

Recreate the containers:

```bash
docker compose down
docker compose up -d --build
```

# Before Ending Each Development Session

I recommend this routine:

```bash
# 1. Check your work
git status

# 2. Save it
git add .

git commit -m "Describe today's work"

# 3. Push to GitHub
git push

# 4. Stop the containers
docker compose down
```

This way, your work is versioned and your machine isn't using resources overnight.
