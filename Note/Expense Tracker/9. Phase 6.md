# My Recommendations Before We Start Coding

Now that the infrastructure is defined, I have three recommendations that will improve your learning experience:

### 1. Use PostgreSQL Everywhere During Development

Don't use SQLite even temporarily. Since your goal is to learn PostgreSQL, start with it from day one.

---

### 2. Delay Celery Until the Core Works

We'll configure Redis and Celery early so you learn how they fit into the architecture, but we won't rely on them immediately. Initial versions can refresh dashboard data synchronously. Once the core financial workflow is stable, we'll move those tasks into Celery.

---

### 3. Add an API Testing Tool

I recommend using **Bruno** instead of Postman.

Reasons:

- Stores collections as plain text in your Git repository.
    
- Works well with version control.
    
- Lightweight and offline.
    
- Easier to review changes.
    

Every API endpoint you build can be tested and versioned alongside the project.
