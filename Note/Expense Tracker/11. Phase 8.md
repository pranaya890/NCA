# STEP 6 – Docker Network

We'll use a single user-defined bridge network.

```text
pfms-network

│

├── django

├── postgres

├── mongodb

├── redis

├── celery

└── nginx
```

Containers communicate using their service names.

Example:

- Django connects to PostgreSQL using `postgres`
    
- Django connects to MongoDB using `mongodb`
    
- Django connects to Redis using `redis`
    

No IP addresses.

# Two Changes I'd Recommend

## 1. Use `uv` Instead of `pip`

Instead of relying on `pip` directly, consider using **`uv`** as your Python package manager.

Benefits:

- Much faster dependency installation.
    
- Creates and manages virtual environments.
    
- Better dependency resolution.
    
- Increasingly popular in modern Python projects.
    

Even though development happens in Docker, `uv` is excellent for managing dependencies and generating lock files.

---

## 2. Use `Taskfile` Instead of Long Docker Commands

Rather than remembering commands like:

```bash
docker compose exec django python manage.py migrate
```

create a `Taskfile.yml` with shortcuts:

```yaml
task: migrate
task: makemigrations
task: shell
task: createsuperuser
task: test
```

This keeps your workflow clean and consistent.
