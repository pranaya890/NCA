# Step 1: Create the Django Dockerfile

Create:

```text
docker/
└── django/
    └── Dockerfile
```

Paste the following:

```dockerfile
FROM python:3.13-slim

# Prevent Python from writing .pyc files
ENV PYTHONDONTWRITEBYTECODE=1

# Flush Python output immediately
ENV PYTHONUNBUFFERED=1

WORKDIR /app

# Install system dependencies
RUN apt-get update && apt-get install -y \
    build-essential \
    libpq-dev \
    curl \
    && rm -rf /var/lib/apt/lists/*

# Install uv
RUN pip install uv

# Copy requirements first (better Docker caching)
COPY backend/requirements/ /tmp/requirements/

# Install dependencies if requirements exist
RUN if [ -f /tmp/requirements/base.txt ]; then \
    uv pip install --system -r /tmp/requirements/base.txt; \
    fi

# Copy project
COPY backend/ /app/

EXPOSE 8000

CMD ["python", "manage.py", "runserver", "0.0.0.0:8000"]
```

### Why this order?

Docker builds in layers. Since requirements change less often than your code, Docker can reuse the dependency layer, making rebuilds much faster.

# Step 1: Create the Nginx Configuration

Create:

```text
docker/
└── nginx/
    └── nginx.conf
```

Paste this configuration:

```nginx
events {}

http {
    upstream django {
        server django:8000;
    }

    server {
        listen 80;
        server_name localhost;

        client_max_body_size 100M;

        location / {
            proxy_pass http://django;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
        }

        location /static/ {
            alias /app/static/;
        }

        location /media/ {
            alias /app/media/;
        }
    }
}
```
