### How is python code executed?
- python code is executed through interpreter which reads and executes code line by line
- when the python code is run, the interpreter translates it to machine code
- which a computer can understand and execute
- the process is started when we invoke the python interpreter by running a script through CLI or executing code inside  an interactive shell
- the interpreter reads the code processes it and output the result into screen
- at first the python code is compiled to intermediate form called bytecode
- this bytecode is not machine specific i.e. it can run on any machine that has compatible python interpreter
- the bytecode is stored in `.pyc` file  which the Python Virtual machine (PVM) uses to execute the code
- the bytecode helps python achieve portability across different platforms without needing to recompile code each time
- after the bytecode is ready PVM takes over which is responsible for reading bytecode and executing it on computer hardware
- it interprets the code at runtime, meaning you can interact with the program while it's running, debugging and modifying it
