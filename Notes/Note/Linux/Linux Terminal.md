Command Line Interface used in Linux to execute command  run scripts and run various cyber security tools
Runs on Z shell but also supports Bash and other shells
Shell /command line / Linux Terminal  is basically a program that acts as the interface between the user and kernel
Provides the text-based I/O interface between user and kernel
Allows user to navigate the file system, managing packages with apt( Advanced Package Tool) and configuring system settings
Linux Terminal is like the Command Prompt in windows but has more functionality 
advanced scripting is done in power-shell instead of CMD
In Linux terminal is more frequent because os is built around command-line-driven environment
Terminal is more preferred by the users to have more control over the system
Many Linux distros (server versions) do not have GUI by default, making the terminal primary way to interact with the system
Terminal also supports scripting language  like Python, Bash, Perl and Ruby enabling automation of security task

### Linux shell prompt structure
```shell
<username>@<hostname><current working directory>$
```
Example
```shell
(pranaya㉿kali)-[~]
```
